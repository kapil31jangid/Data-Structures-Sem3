# Unit 1 - Viva Questions

[← Important Questions](important-questions.md) | [Unit Index →](README.md)

Open each question only after attempting it aloud.

<details>
<summary><strong>1. What is data?</strong></summary>

Data is a basic fact or entity used in calculation or manipulation.

</details>

<details>
<summary><strong>2. What are the two types of data introduced here?</strong></summary>

Numeric data and alphanumeric data.

</details>

<details>
<summary><strong>3. What is representation?</strong></summary>

Representation is the process of storing data items in a computer's main
memory.

</details>

<details>
<summary><strong>4. What is a data structure?</strong></summary>

A data structure is a logical or mathematical model used to organise data items
and represent their relationships.

</details>

<details>
<summary><strong>5. What four things does a data structure specify?</strong></summary>

Organisation of data, accessing methods, degree of associativity, and
processing alternatives.

</details>

<details>
<summary><strong>6. What is a storage structure?</strong></summary>

It is the representation of a particular data structure in computer memory.

</details>

<details>
<summary><strong>7. What is a file structure?</strong></summary>

It is the representation of a storage structure in auxiliary memory.

</details>

<details>
<summary><strong>8. Name four primitive data structures.</strong></summary>

Integer, float, character, and pointer.

</details>

<details>
<summary><strong>9. Name three non-primitive data structures.</strong></summary>

Array, list, and file.

</details>

<details>
<summary><strong>10. Give examples of linear data structures.</strong></summary>

Stack and queue.

</details>

<details>
<summary><strong>11. Give examples of non-linear data structures.</strong></summary>

Tree and graph.

</details>

<details>
<summary><strong>12. What is traversal?</strong></summary>

Traversal is the systematic process of visiting every node or element of a
data structure.

</details>

<details>
<summary><strong>13. How does selection differ from searching?</strong></summary>

Selection accesses particular data, while searching checks for the presence or
location of a desired item.

</details>

<details>
<summary><strong>14. What is algorithm analysis?</strong></summary>

It is the evaluation of an algorithm's efficiency in terms of execution time
and memory usage.

</details>

<details>
<summary><strong>15. What is time complexity?</strong></summary>

It describes how an algorithm's number of elementary operations grows with
input size.

</details>

<details>
<summary><strong>16. What is space complexity?</strong></summary>

It describes how an algorithm's memory requirement grows with input size.

</details>

<details>
<summary><strong>17. What is the best case?</strong></summary>

The minimum time required by an algorithm for an input of a given size.

</details>

<details>
<summary><strong>18. What is the average case?</strong></summary>

The expected time required over possible inputs under stated assumptions.

</details>

<details>
<summary><strong>19. What is the worst case?</strong></summary>

The maximum time required by an algorithm for an input of a given size.

</details>

<details>
<summary><strong>20. What does Big O represent?</strong></summary>

An asymptotic upper bound.

</details>

<details>
<summary><strong>21. What does Omega represent?</strong></summary>

An asymptotic lower bound.

</details>

<details>
<summary><strong>22. What does Theta represent?</strong></summary>

A tight asymptotic upper and lower bound.

</details>

<details>
<summary><strong>23. What is linear search's best-case complexity?</strong></summary>

`O(1)`, when the key is at the first position.

</details>

<details>
<summary><strong>24. What is linear search's worst-case complexity?</strong></summary>

`O(n)`, when the key is last or absent.

</details>

<details>
<summary><strong>25. Why is average linear search O(n), not O(n/2)?</strong></summary>

Asymptotic notation ignores constant factors. Therefore, linear growth of
`n/2` is written as `O(n)`.

</details>

## Viva Readiness

- [ ] I can give one example when the examiner asks a follow-up.
