# CEM2003C - Data Structures

A comprehensive repository for learning and practising Data Structures for Semester 3.

The repository is designed to help students:

- Understand Data Structures from fundamentals
- Implement algorithms in C
- Complete laboratory practicals
- Prepare for practical examinations
- Prepare for viva examinations
- Revise concepts for theory examinations

## Course

- **Course:** Data Structures
- **Course Code:** CEM2003C
- **Semester:** 3
- **Programme:** B.Tech CSE
