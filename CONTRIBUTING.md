# Contributing

Contributions are welcome.

## Guidelines

1. Code should be beginner-friendly.
2. Avoid hardcoded input wherever user input is appropriate.
3. Programs must compile successfully.
4. Use meaningful variable names.
5. Add comments only where they improve understanding.
6. Include sample input and output.
7. Include the algorithm where applicable.
8. Mention time and space complexity.
9. Avoid duplicate solutions.
10. Keep programs aligned with the course syllabus.
